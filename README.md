# XAMPP Updater

Windows용 XAMPP 구성요소 업데이트 도구입니다.

대상 구성요소는 **Apache / PHP / MariaDB**로 제한합니다. XAMPP 전체를 재설치하지 않고 현재 설치를 감지하고, 구성요소별 버전 확인과 향후 안전한 업데이트·설정 백업/복원/비교를 제공하는 GUI 도구를 목표로 합니다.

## 현재 상태

Phase 1 개발 시작 단계입니다.

- Windows 11 우선 지원
- XAMPP 설치 경로 자동 감지 및 직접 지정
- Apache / PHP / MariaDB 설치 여부와 로컬 버전 감지
- 이후 Phase에서 최신/선택 버전 조회, 백업, 업데이트, 설정 비교/복원 기능 추가

자세한 개발 범위와 결정사항은 `docs/ROADMAP.md`, `docs/DECISIONS.md`를 참고하세요.
